# Care-Hope

A professional doctor appointment management website for patients, doctors,
and administrators. The project will be built incrementally with HTML, CSS,
JavaScript, PHP, and MySQL.

## Project plan

The first implementation step establishes the recommended application layout
and relational database schema. See:

- [`docs/project-structure.md`](docs/project-structure.md) for the folder
  structure, page map, and build sequence.
- [`database/schema.sql`](database/schema.sql) for the MySQL database and
  starter tables.

## Planned stack

- **Frontend:** HTML5, CSS3, and vanilla JavaScript
- **Backend:** PHP with PDO prepared statements
- **Database:** MySQL
- **Security:** PHP password hashing, server-side validation, CSRF protection,
  session controls, and parameterized database queries
